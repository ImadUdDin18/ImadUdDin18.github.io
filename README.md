# Imad Ud Din — DevOps Engineer Portfolio

A personal portfolio website for **Imad Ud Din**, showcasing cloud infrastructure, DevOps automation, containerization, CI/CD, and selected GitHub projects.

## Highlights

- AWS and cloud infrastructure focus
- Docker, Terraform, Kubernetes, Linux, and CI/CD skills
- Selected projects linked to Imad's GitHub profile
- Responsive layout with animated interactions
- Dark and light viewing modes
- Contact section and professional profile links

## Getting Started

Install the dependencies and start the development server:

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production Build

```bash
pnpm build
pnpm start
```

## Project Structure

- `app/page.tsx` — portfolio content and sections
- `app/globals.css` — visual system, responsive layout, and animations
- `app/layout.tsx` — metadata and application shell
